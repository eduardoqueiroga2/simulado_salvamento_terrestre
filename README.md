# Simulado de Salvamento Terrestre — GitHub Pages

## Arquivos
- `index.html`: quiz interativo com 90 questões.
- `RESUMO-SALVAMENTO-TERRESTRE.pdf`: resumo de 28 páginas.
- `APRESENTACAO-SALVAMENTO-TERRESTRE.pdf`: apresentação de aula em PDF, 56 páginas.

## Publicação
1. Extraia o ZIP.
2. Envie os três arquivos para a raiz do repositório GitHub Pages.
3. Em Settings → Pages, mantenha a configuração de publicação já usada no projeto.
4. Abra o endereço publicado e teste os botões Resumo e Apresentação.

## Recursos
- 90 questões: 30 fáceis, 30 médias e 30 difíceis.
- Cinco alternativas por questão (A–E).
- Feedback didático após selecionar a alternativa, com referência à página do resumo e ao slide da apresentação.
- Filtro por dificuldade, navegação por números, anterior/próxima, resultado e salvamento local do progresso.
- Layout responsivo com a pergunta antes do painel lateral no celular.

## Nota
O simulado foi montado com base nos dois PDFs fornecidos. As referências são guias de consulta ao material, não uma certificação independente de doutrina ou de normas operacionais. Confirme procedimentos e itens sensíveis com o instrutor e fontes oficiais vigentes.
